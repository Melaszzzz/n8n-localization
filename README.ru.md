# Локализация n8n — языковой пакет для китайского, испанского и русского

Документация: [English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | Русский

Локализация интерфейса для уже развёрнутых self-hosted установок n8n: упрощённый китайский (`zh-CN`), традиционный китайский (`zh-TW`), испанский (`es`) и русский (`ru`). Проект содержит только файлы перевода и обратимый установщик; сам n8n он не включает, не устанавливает и не распространяет.

## Доступные языковые пакеты

| Код | Язык | Статус | Полная базовая версия |
| --- | --- | --- | --- |
| `zh-CN` | Упрощённый китайский | Завершён | n8n 2.38.6 |
| `zh-TW` | Традиционный китайский (Тайвань) | Предварительная версия | n8n 2.38.6 |
| `es` | Испанский | Предварительная версия | n8n 2.38.6 |
| `ru` | Русский | Предварительная версия | n8n 2.34.6 |

Русский перевод подготовлен для n8n 2.34.6. Дополнительные 883 ключа из n8n 2.38.6 пока сохранены на английском и ожидают перевода.

Языки со статусом «предварительная версия» имеют полное автоматическое покрытие ключей и проходят проверки установщика, но им ещё требуется вычитка в реальном интерфейсе n8n носителем языка. Планируемые языки и условия их выпуска описаны в [дорожной карте локализации](ROADMAP.md).

## Зачем этот пакет

- Устанавливается поверх существующей установки n8n и не заменяет всю сборку редактора.
- Все изменения учитываются в манифесте, поддерживается безопасное удаление.
- Интерфейс и параметры узлов переводятся двумя отдельными совместимыми механизмами.
- Используется только точное совпадение исходного текста. Неизвестный или изменившийся текст остаётся на английском.
- Рабочие процессы, учётные данные, базы данных, полезная нагрузка API, пользовательский ввод, код и выражения не изменяются.
- Проверено на macOS, Windows и Linux.

## Совместимость

- Self-hosted n8n, установленный локально или глобально через npm.
- macOS, Windows и Linux.
- Docker — если установщик запускается на этапе сборки образа.
- Версии n8n, отличные от базовой, допускаются: несовпавшие строки остаются на английском.
- n8n Cloud не поддерживается, потому что файлы его редактора изменить нельзя.

## Установка

Требования: работающая установка n8n и Node.js 18 или новее.

Список доступных языков:

```bash
npx --yes --package git+https://github.com/Melaszzzz/n8n-localization.git n8n-localize --list-locales
```

Установка русского языка:

```bash
npx --yes --package git+https://github.com/Melaszzzz/n8n-localization.git n8n-localize --locale ru
```

Для других языков укажите `--locale zh-CN`, `--locale zh-TW` или `--locale es`. Перед установкой предварительной версии установщик выводит предупреждение.

Если n8n не удаётся найти автоматически, укажите каталог проекта, `node_modules` или каталог пакета:

```bash
npx --yes --package git+https://github.com/Melaszzzz/n8n-localization.git n8n-localize --locale ru --target /path/to/n8n/project
```

Windows PowerShell:

```powershell
npx --yes --package git+https://github.com/Melaszzzz/n8n-localization.git n8n-localize --locale ru --target "C:\path\to\n8n\project"
```

После установки перезапустите службу n8n и перезагрузите редактор без кеша браузера.

Если пакет оказался полезен, добавьте репозиторий в избранное, чтобы следить за обновлениями языков.

## Удаление

```bash
npx --yes --package git+https://github.com/Melaszzzz/n8n-localization.git n8n-localize --locale ru --uninstall
```

Программа удаления восстанавливает только файлы, которыми управляет этот проект. Файлы, изменённые после установки, сохраняются, и о них выводится сообщение. Перед переключением на другой язык удалите активный.

## Принципы перевода

- Приоритет отдаётся штатному механизму перевода узлов n8n; ограниченный оверлей интерфейса используется только для текста, который иначе не переводится.
- Устоявшиеся технические термины — AI, API, HTTP, JSON, MCP, Webhook — остаются на английском.
- Неоднозначные и связанные с безопасностью термины могут дублироваться на двух языках, если это повышает точность.
- Никогда не переводятся код, выражения, пользовательские данные, значения полей, исходный текст ошибок, названия рабочих процессов и учётных данных, а также секреты.
- Нечёткое сопоставление и замена по подстроке не используются.

## Для ИИ-ассистентов

Приведённые команды применимы только тогда, когда у пользователя уже есть self-hosted установка n8n. Подробности о поиске цели, работе с Docker, ограничениях безопасности и восстановлении — в [AI_INSTALL.md](AI_INSTALL.md). Машиночитаемые метаданные языков находятся в [locales.json](locales.json).
