# Spanish locale review status

Status: **preview — complete machine candidate, native UI review still required**.

## Source and generation

- English source baseline: all keys in `localization/parts/*.json` for n8n 2.34.6.
- The Chinese translations were not used as translation input.
- High-frequency batches were generated from English-only JSON through the locally available Codex CLI.
- The 26,244-entry node long tail was generated by offline `Helsinki-NLP/opus-mt-en-es` inference, followed by deterministic terminology and safety passes.

## Independent review performed

- Full key-set comparison against all 30 English source parts.
- Placeholder, HTML tag, URL, fenced/inline code, `<code>/<pre>`, pipe-form, and technical-token parity checks.
- Restoration of 202 unsafe code, JSON, CSV, query, expression, or mixed code/prose candidates to their exact English source.
- Terminology normalization across 896 candidate values, including `Agregar`, `flujo de trabajo`, `nodo`, `activador`, `ejecución`, `credencial`, `elemento`, `tabla de datos`, and `Agente de AI`.
- 171 additional reviewed overrides beyond the original 23 override keys, resolving cross-part conflicts and improving frequent UI text.
- Focused review of core UI, credentials, settings, Schedule Trigger, Webhook, AI Agent, HTTP Request, and Data Table surfaces.
- Direct English translation and a separate correction pass for the 801-string n8n 2.34.6 increment.
- Installer/package validation through `npm test`.

## Publication boundary

All source keys now have a structurally safe Spanish candidate, but coverage is not the same as native linguistic quality. Long-tail descriptions still contain machine-generated Spanish and intentionally preserved English technical examples. A native or professionally fluent reviewer should check tone, regional neutrality, gender/number agreement, product context, and representative rendered screens on macOS, Windows, and Linux.

The locale may be distributed only as a clearly labeled preview until that UI review is complete.
